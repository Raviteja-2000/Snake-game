# Snake game

Version: v2.0.0

A responsive, vanilla JavaScript Snake game with touch and keyboard controls, local leaderboard, theming, and improved rendering.

See CHANGELOG.md for full details on what changed in this release.

Running locally
- Clone or download the repository and open `index.html` in a browser.

Notes
- If you previously ran an older copy and do not see UI improvements, clear your browser cache or pull the latest changes: `git pull origin main`.
- Settings and leaderboard are stored in localStorage (keys prefixed with `snake_ultra_`). Clearing site data will reset them.
